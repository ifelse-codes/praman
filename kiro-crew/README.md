# PRAMAN Kiro Crew App

A Kiro Crew app that wraps the PRAMAN MCP server. Agents in a crew can invoke `praman_verify` to experience, stimulate and review generated software, returning evidence-backed findings.

## Usage
1. Start PRAMAN MCP: `praman mcp`
2. Configure Kiro Crew to load this app's agents.
3. Ask the crew to verify a generated app directory.
