#KiroweenHackathon26 Favorite thing about Kiro: hooks plus specs. I put PRAMAN, my evidence-first verification tool, behind Kiro's Stop hook: when the agent says "done", the declared checks run again, and a failing one sends the agent back to work. Then I let Kiro agents fix PRAMAN itself the same way: show the bug on a real run, write the spec, fix it, prove it with PRAMAN. It changed my approach from "trust the summary" to "show me the run". PRAMAN's original engine was built before Kiro; the write-up says exactly what Kiro did. https://github.com/ifelse-codes/praman · <DEMO_VIDEO_URL>
