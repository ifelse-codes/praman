# External archive — 2026-11-05 cleanup

This repository was reduced to the product on 2026-11-05 under explicit owner
authorization. Removed material was preserved in an external archive **outside**
this repository, because it contains private host paths, sessions, credentials,
third-party source snapshots and agent process logs that must not be published.

## What the archive holds

- **Evidence:** selected proof trees and receipts, including the Headlamp tooltip
  repair and dry-run preview, the Kan attachment/checklist campaigns, the Stern
  repair, the jq command movie, the 12-outcome first-use matrix, and the release
  candidate receipts.
- **Movies:** the accepted narrated walkthroughs, preserved as encoded MP4s.
- **Documents:** the master handoff, roadmap, dated history, research export,
  session prompts, execution/proof plans, workspace-cleanup log and the stale
  submission drafts (blog, social, demo script, vision export).
- **Code:** the removed legacy modules and the target-specific reference
  integrations, plus the target-specific example directories.
- **Metadata:** archive index, inventory and hashes.

## How to use it

The archive is not part of this repository, its package or any release. Ask the
owner for its location. Do not copy raw evidence, credentials or third-party
source snapshots back into the repository. If a remaining document refers to an
archived receipt it should say so and state the limitation, not link a path that
does not exist here.

## Why not keep it in the repository

- Publication would leak personal data and private infrastructure state.
- Raw evidence is large (5.7 GB, 133k files) and unrelated to using the product.
- Historical process logs and stale drafts describe superseded plans and can
  mislead reviewers; the current product documentation is README, first-use,
  static-browser acceptance, release validation, video guidelines and this
  status/cleanup pair.
